# Pinoy links

**Website: https://pinoylinks.github.io**

Welcome to Pinoy Links — a site dedicated to collecting relevant and useful links in the Pinoy World Wide Web, so you don't have to.

[👉 Install pinoy links](https://pinoylinks.github.io/about/#install)

## Features

1. Discover interesting Filipino content.
2. Quickly find what you're looking for.
3. Find links by [topic](https://pinoylinks.github.io/tag-cloud).

## How to install pinoy links

### In Mobile

1. Go to https://pinoylinks.github.io/ (not in incognito mode).
2. Go to Menu.
3. Install and create shortcut.

![Install pinoy links in mobile](https://pinoylinks.github.io/about/install-pinoylinks-in-mobile.jpg)

### In Desktop

1. Go to https://pinoylinks.github.io/ (not in incognito mode).
2. In address bar, Click install pinoy links.

![Install pinoy links in desktop](https://pinoylinks.github.io/about/install-pinoylinks-in-desktop.png)
