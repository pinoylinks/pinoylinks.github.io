### In Mobile

1. Go to https://pinoylinks.github.io/ (not in incognito mode).
2. Go to Menu.
3. Install and create shortcut.

![Install pinoy links in mobile](install-pinoylinks-in-mobile.jpg)

### In Desktop

1. Go to https://pinoylinks.github.io/ (not in incognito mode).
2. In address bar, Click install pinoy links.

![Install pinoy links in desktop](install-pinoylinks-in-desktop.png)
